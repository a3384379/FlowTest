S22　V3 架构基线
核心迭代
  • Capability SDK V3、Runner 抽象
  • 统一 Node Result / Execution Event
  • Plugin Manifest 与 Feature Flag
  • V2 Workflow 无迁移运行
退出标准：新旧节点可混合执行；Snapshot 锁定 Capability 版本。
S23　GraphQL + gRPC
核心迭代
  • GraphQL Schema / Introspection、Query/Mutation
  • Proto / Reflection 导入
  • gRPC Unary、Server Streaming
  • TLS / mTLS 与数据绑定
退出标准：REST、GraphQL、gRPC 可在同一 Workflow 关联。
S24　Kafka + WebSocket
核心迭代
  • Kafka Produce / Consume、Correlation
  • Schema Registry 支持
  • WebSocket Connect / Send / Await / Assert
  • 超时与消息上界
退出标准：禁止无限消费与无限等待；日志统一脱敏。
S25　Performance Lab
核心迭代
  • k6 Runner、声明式场景建模
  • VU / Ramp / Duration / Threshold
  • 基线对比与实时指标
  • 性能结果进入 Quality Gate
退出标准：无需写 JS 即可完成 HTTP 压测；Runner 与业务 Worker 隔离。
S26　Environment Lab
核心迭代
  • Environment Template
  • 临时环境 Provision / Health Check
  • Seed / Cleanup / TTL
  • Testcontainers / 受控 Compose
退出标准：环境可自动创建、失败清理、TTL 销毁；网络与 Credential 策略继续生效。
