## 保留的契约

流程定义仍通过既有 onChange → 本地草稿 → 显式保存链路更新；选择、宽度、焦点和拖动预览不进入服务端定义。保持 capability 原始表示、未知配置、映射变换、清理元数据、运行输入及本次编辑器不负责的 request_overrides 字段。沿用保存 revision/generation 并发保护，不隐式保存后发布。不增加服务端路由、执行引擎、数据库结构、日志或脱敏策略变更。

## 计划符号与组织差异

图分析与命令分布在 `flow/editor/graph-analysis.ts` 和 `graph-commands.ts`；Canvas 适配仍集成在 WorkflowDesigner，未仅为文件命名再拆一层。节点库以 typed group 描述和现有节点创建函数实现，未另造一套服务端节点注册表。请求抽屉与 Inspector 最大化各自保持同一组件实例，原始表单通过 DraftSession 会话恢复。上述为内部组织差异，不能替代交互验收。

三档人工截图为 1920×1080、1440×900、1280×720。页面无纵向溢出，1280 下缩小页面留白并隐藏 MiniMap，专注模式使用完整可用画布。右栏真实分隔条拖动调宽已通过。

真实浏览器发现并修复的问题包括：受控 React Flow 节点重建时缺少测量值导致连线未显示，现通过 UI 专用 `canvas-dimensions` 缓存保留测量，测量不写入定义；长侧边栏撑高工作区，现限定工作流路由的应用壳高度并让侧边栏独立滚动。历史快照省略空 condition 时按普通边处理；历史结果区默认折叠，低高度画布隐藏小地图，避免遮挡结束节点。恢复未应用会话后点击当前节点不会误弹“切换前应用”。发布确认对用户/项目/工作流/服务器草稿 revision/权限校验，并显式绑定发布目标；等待期间变更则取消。保存后关闭页签的接口在未应用配置或结构校验失败时明确 reject，沿用页签层失败保持打开语义。
