## 2. 已完成的优化

### 2.1 Layout Foundation

- 默认编辑态使用单一 Workbench Header，合并模式切换、保存、运行、调试和更多操作。
- 1440 宽度下 Workflow List 为 `256px`，位于 `240~280px` 契约范围。
- 默认 Edit、Runtime Dock 关闭时，1440 Canvas Stage 达到 `600px` 高度底线。
- Inspector 展开和拖宽时，Canvas 相对 `EditorMain` 的宽度占比保持不低于 `52%`。
- 1280、1440、1920 三档高度链均由 Geometry Playwright 实测通过。
- 移除旧固定 `540px` 画布和冲突双栏规则；新样式限制在 workflow workbench scope 内。
- Focus Mode 真正隐藏外围导航，并保留保存、运行、调试、Add Node、Undo/Redo、自动布局、适应画布和退出入口。

### 2.2 Selection、Edge 与快捷键

- Selection 收敛为 `node | edge | null`，节点、连线、画布空白三种选择互斥。
- 节点旁提供配置、复制、删除浮动操作；连线旁提供映射和删除浮动操作。
- 删除、复制、粘贴、Undo/Redo、配置打开均复用 editor command/history，不维护第二套状态。
- Edge reconnect 保留 edge id，并同步 mapping 的 source/target endpoint；删除和重连可原子撤销。
- Tab 只在画布焦点态打开 Add Node；Shift+Tab、输入控件、弹层和 IME 不被接管。
- Delete、C、V、Z、Enter、F、Esc 的保护条件和帮助面板保持一致。
- 画布或 Inspector 宽度变化时，选中节点/连线保持清晰可见，避免重新缩放为不可读的小节点。

### 2.3 Node Library 与 Inspector

- Add Node 改为真正的 portal Drawer，宽度 `400px`，Focus Mode 下不会与顶部工具栏重叠。
- 节点分类统一为“基础、接口协议、控制与校验、数据与存储、流程复用”。
- 节点卡片提供图标、名称、用途、可用状态、资源选择和逐项不可用原因。
- 搜索覆盖节点名称、协议、用途和关键词。
- Quick Inspector 支持 `320~640px` 拖动和布局偏好保存；默认宽度 `400px`。
- Fullscreen Node Configuration 使用基本信息、请求目标、Params、Headers、Body、Auth 等语义区块，并复用同一个 NodeEditSession。
- API Request Editor 只 patch 自己拥有的字段，保留 auth、suppressed、timeout、retry、polling 等现有 override 字段。

### 2.4 Runtime 与 History Workbench

- 原页面下方独立执行 Card 已移除。
- Run、Debug、History 使用同一 Workbench 和同一 Runtime Dock。
- Runtime Dock 可折叠，实测高度位于 `200~280px` 范围。
- Run/History 继续使用现有 execution、snapshot、replay 和 repair 数据源，没有新增不存在的调试后端。
- History 快照明确只读，画布与快捷键不能修改 definition。
- 历史视图截图会等待 snapshot 和 React Flow 节点加载完成，避免把 Skeleton 当成验收结果。
