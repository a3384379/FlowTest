# Architecture Decision Records

使用顺序编号记录会长期影响架构的决策。S0 至少补齐：

1. 模块化单体与执行平面边界
2. 变量/Header 作用域
3. Workflow 持久化格式
4. Execution Snapshot 与状态机
5. 后台执行与实时事件传输
6. 数据集、字段映射与条件分支语义
7. 持久化任务分发、测试计划与外部触发
8. 派生执行报告、HTML 产物与签名通知
9. 治理权限、出站网络与幂等边界
10. 保留期、可观测性与可恢复发布
11. 测试资产不可变版本与计划目标快照
12. 高级工作流节点、固定子流程快照与安全表达式
13. 只读数据节点、加密 Credential 与规则化 Mock
14. 契约生成、破坏性变更与人工审核
15. Cron 调度、质量门禁与持久队列容量
16. 企业身份、外部密钥、分布式追踪与时间点恢复
17. AI 建议、人工审核与数据边界
18. Capability SDK、Legacy Adapter 与 Runner 安全边界
19. 多协议 Schema、执行边界与 Snapshot
20. 事件协议、消息 Schema 与 WebSocket 会话边界
21. 声明式性能场景、固定 k6 编译器与隔离 Runner
22. 管理员签名环境模板、镜像白名单与幂等隔离 Provision Runner
23. Pact 契约仓、Service Graph 与发布证据
24. 多源变更影响与确定性测试选择
25. PostgreSQL Lease/Fencing 与隔离 Runner 执行面
