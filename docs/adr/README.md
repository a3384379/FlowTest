# Architecture Decision Records

使用顺序编号记录会长期影响架构的决策。S0 至少补齐：

1. 模块化单体与执行平面边界
2. 变量/Header 作用域
3. Workflow 持久化格式
4. Execution Snapshot 与状态机
5. 后台执行与实时事件传输
6. 数据集、字段映射与条件分支语义
7. 持久化任务分发、测试计划与外部触发
8. 派生执行报告、HTML 产物与签名通知
9. 治理权限、出站网络与幂等边界
10. 保留期、可观测性与可恢复发布
11. 测试资产不可变版本与计划目标快照
12. 高级工作流节点、固定子流程快照与安全表达式
13. 只读数据节点、加密 Credential 与规则化 Mock
14. 契约生成、破坏性变更与人工审核
