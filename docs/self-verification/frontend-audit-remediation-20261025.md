## 数据与恢复边界

- 新增普通用户只读 `GET runs/{id}/insights`，继续执行项目授权。工件必须属于当前批次、项目、摘要和完整冻结场景集合；即使另一份工件尚未形成，也不能借用其他场景补分母。共享工件读取预算为 16 MiB、5 秒，单字段较大时明确给出数量和摘要，完整内容仍由既有授权下载读取。
- 协议、设计指标基于已上传生成回执，未记录调用和未上传场景明确排除；首次与辅助批次分开。来源结构完整率与原始执行是否符合分开，不能因原始失败就抹去有效来源，也不能把 matched 改写为引擎 passed。
- 历史批次未保存的编译详情、槽位或观察字段不能反推；界面明确标注未记录或未评估。对照中的字段差异用于定位，场景和批次裁决仍来自原独立核验回执。
- 安装恢复使用原 ID、原 nonce、原资源映射和宿主状态目录。有效租约期间、已就绪或归档的安装不能恢复；状态不确定时不会另建安装或盲目重放资源创建。未知创建结果仍须原宿主按 journal 核对。
- 本轮没有数据库模型或迁移变更，没有增加日志采集，没有调用真实模型，也没有由网页创建 Docker 环境或授予代理权限。
