## 使用与验收边界

- 命令意图缓存覆盖当前 QueryClient 生命周期的关闭重开、范围切换和迟到回执。完整浏览器刷新会清除该内存；不能据此承诺跨刷新仍保留原请求键。需从现有安装及批次回执确认结果。
- 取消轮询有上限；到达上限后保持实际状态，用户可手动刷新。已请求取消不等于原生执行已完成清理。
- stage/finalize 增加了 H 与服务端的协议要求；旧宿主只调用一次 materialized 时会停在 publishing，不能被当成可执行。需配套更新实际 H 脚本。
- 私有宿主 journal、nonce 与原租约必须保留；不能用新 nonce 猜测或重放结果未知的写操作。
- 本轮不调用真实模型。合成 API、模拟模型和独立浏览器测试均不能证明真实 H/O 接入、人工审核或真实模型闭环。
- 本轮开工检查时 Docker 未运行；本轮没有更新、重启或替换 13078 的历史部署，也没有声称旧环境代表当前源代码。
- 未执行 Compose、Compact、Standalone 三形态端到端验收或 Windows 打包；本地合成检查不替代发布验收。
- 修改保留在原任务工作树；未自动提交、推送、合并，远程当前提交门禁及发布验收分别确认。
