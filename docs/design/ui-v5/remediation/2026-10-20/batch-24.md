# 第二十四批：M22 AI 变更集

对应冻结审计 [F-AIC-01 / 02 / 03](../../audits/2026-10-19/complete-audit.md#m22) 和[修改方案](../../audits/2026-10-19/remediation-plan.md#m22)。本回执记录实施结果；原审计和方案保持冻结。

## 实施结果

- 审核面板同时呈现固定风险、影响分析、AI 任务、来源指纹和完整来源快照。目标资产在进入生成队列前冻结名称、说明、定义、标签及版本等已授权材料，独立存储为 `review_baselines`，不改变原 AI 输入指纹。生成期间资产漂移仍由服务端冲突校验阻止接受。
- 修改项按目标类型、ID 和快照哈希匹配唯一冻结基线，展示修改前、修改后及逐字段差异，数组替换和空补丁按服务端语义处理。不能唯一匹配、旧记录没有基线时明确说明，不读取当前资产冒充历史。完整 JSON 可展开核对。
- ON 使用已有策略投影，并明确可读投影与完整快照哈希的范围；OFF 显式跳过扫描、遮盖和替换。策略模式和版本随基线固定，未增加 Secret 读取、日志或诊断采集。
- 展示审核人、时间和备注；接受成功后依据真实返回的资产类型、ID 打开 Workflow 或用例草稿，未知类型不猜测链接。普通 AI 助手仍禁止审核 `change_set` 类型，不能绕过专用接受流程。
- 编辑 JSON 和备注后的关闭、路由切换、刷新具有输入保护；失败保留原材料，显示标准错误与 Trace，不自动重复提交。同一命令期间阻止重复写入；切项目、卸载后的旧响应不更新当前工作区。
- AI 与质量智能关闭时，保留原项目读取授权下的列表、详情和物化草稿入口；关闭生成、审核写入及轮询，不持续请求被关闭的能力。创建仍同时要求 AI、质量智能、影响分析能力及编辑权限。
- 风险目录使用服务端真实分页，分页留在创建窗口内；切页保留已选风险及同源影响。限定每页20项的选择器支持搜索，避免虚拟列表滚动导致选项不可点击。
- 新增可回滚迁移 `0065`，旧记录默认空基线；不以当前定义回填旧历史。

## 独立复审：前端差异与审核归属（2026-10-22）

复审复现了两个实际缺陷：定义对象浅替换会把后端保留的省略运行时字段展示为删除；同一项目从 focus B 返回 A 并确认放弃后，旧 B 表单仍保留，来源却已经切为 A。本节只记录前端补修；OFF 下占位符恢复问题由独立后端提交处理，旧完整后端结果不能作为组合修复后的验证结果。

- 差异按冻结目标类型推导：Test Case 省略 `runtime_variables/runtime_headers` 时保留冻结值；Workflow 省略 `variables` 及按节点 ID 匹配的配置字段时保留冻结值。显式提供的空对象仍按替换处理，删除节点不复活，不修改原基线，也不扫描或替换字面占位符。数组仍按完整替换比较。
- 将原“拟写入草稿完整内容”明确为“按更新规则合并的草稿预览”，解释省略保留与显式替换，并说明接受时仍需服务端校验和规范化；不将客户端推导冒充最终规范化回执。ON 继续只展示已授权冻结投影，不读取当前资产或隐藏字段。
- 审核选择用现有路由范围状态绑定项目和当前 ChangeSet，并显式保存 ChangeSet ID 核对来源。确认离开到另一 focus 后销毁旧表单及放行标识；取消导航保留当前输入。相同 ChangeSet 的详情刷新失败和重试成功均不清空 JSON 或备注。
- 真实 Data Router、页面、查询 Hook 和 MSW 反例覆盖 B→A 导航、取消与确认放弃、新项再次触发导航保护、向新项 ID 提交、同项 503 后恢复、旧审核回执晚到不重开旧表单或宣告旧结果。另有页面级预览验证，确认省略的用例运行时字段保留在合并预览中，未被列为删除。
