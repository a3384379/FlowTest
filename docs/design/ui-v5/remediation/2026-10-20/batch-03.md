# 接口范围导出补充整改

日期：2026-10-20。对应 `F-API-04`，将首批的范围说明补齐为实际可用的服务端范围导出。

## 交互与合同

- 导出面板可选择整个项目、当前分组（仅本级，不含子分组）、未分组或已勾选接口；显示当前服务端数量或显式选择数量。
- 搜索和方法筛选不改变导出范围。跨页选择保留并明确显示；切换项目不会借用另一项目的选择。
- 使用各接口已保存的当前版本，保留 HAR、cURL、Bruno、Excel 的文件名、错误处理与既有项目策略。
- 全项目保留旧 GET 合同；新增 POST 合同接收明确的范围和 ID 集合。所选每次 1–1000 个且不能重复；分组或项目导出最多 10000 个，超限拒绝而不截断。
- 服务端先授权项目，再验证分组及每个所选接口属于项目且有效；缺失、归档或跨项目 ID 不会被静默跳过，也不会退回全项目导出。未分组和具体分组不能混选。
- Viewer 可以勾选并导出其可读接口；移动与其他写操作仍需编辑权限。下载失败保留面板和范围；下载期间禁用变更与重复提交。
