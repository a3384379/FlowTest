# UI 设计基线

当前 UI 方向：浅色、高信息密度的企业开发工具风格，参考 Linear、Postman、n8n 与 GitHub Actions。

- V3 主色：`#5b5cf0`；深色导航：`#101936`；成功、失败、运行、跳过使用统一语义色。
- 侧栏约 220～240px，节点属性面板约 340～400px。
- API 路径、变量、代码和 JSON 使用等宽字体。
- Workflow 页面采用左节点库、中画布、右属性、底日志、顶操作栏布局。
- V3 HTML 设计源与 2560×1440 视觉基准位于
  [`FlowTest_V3_UI_CN_HD`](../../FlowTest_V3_UI_CN_HD/README.md)，并补充 1440×900 桌面验收；
  不承诺移动端布局。
