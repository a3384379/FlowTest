# UI 设计基线

当前基线为 v5 冰蓝白：浅色导航、工作区、画布、代码区和弹层，系统深色模式下也使用同一套浅色语义色。

- 主操作色 `#1765E8`，工作区 `#F3F8FF`，画布 `#F7FBFF`。源码颜色入口为 `frontend/src/theme/ice-theme.ts`。
- 常用任务栏 68px；26 个模块保留在可搜索的模块目录。流程检查器默认 320px，小视口使用抽屉。
- 流程编排保留真实节点和端口、内联控制区域、应用/保存/发布/执行的生命周期；接口管理采用目录、请求、响应工作区。
- 报告详情采用执行轨迹与证据工作区，可按执行、节点、请求尝试次数定位历史画布，并从画布返回完整报告。流程设置、来源定位与检查器配置/输入输出/校验均连接已有定义和处理器。
- 1440×900、1280×800、1600×1000 是桌面核对视口；390px 报告采用单列证据和表格内部滚动。
- 当前实现、验证范围及必要视觉差异见 [实施记录](ui-v5/implementation.md)、[视觉差异](ui-v5/visual-deviations.md) 和 [80 项验收矩阵](ui-v5/acceptance.csv)。

历史 V3 设计源保留在 [`FlowTest_V3_UI_CN_HD`](../../FlowTest_V3_UI_CN_HD/README.md)。其中紫色主色、深色导航和旧面板尺寸已由 v5 替代。
