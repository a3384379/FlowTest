控制块模板共 11 类：集合遍历、重复次数、IF、Switch、While、DoWhile、Until、Parallel、Try、步骤组、主动失败。Break、Continue、Return 已有运行契约，但尚无安全的普通画布添加入口，只能作为区域定义的一部分。面板提供配置与区域 JSON 编辑，尚未实现设计文档要求的内联区域可视化编辑。选中无字段映射的连线后添加控制块，可在一次编辑中完成插入与自动布局；有映射的连线会拒绝直接插入。

## 兼容、部署与风险

- 本阶段没有数据库结构变更；实例记录复用现有 checkpoint 持久化。旧 worker 不应调度 schema `4.0` 快照，能力握手完成前不能宣称滚动部署安全。
- 内联子节点在一次区域执行中写入 checkpoint；尚未证明任意进程崩溃点的外部副作用只发生一次。对于已送达外部系统、结果不确定的写操作，不能自动重发或宣称回滚。
- 单进程共享许可不等于跨 worker 全局限流。并发控制能力目前适合受控验证，不应据此承诺分布式全局 QPS。
- AI provider 契约仅允许空 `regions`，明确不生成或修改内联区域；旧 AI 草稿保持原有行为。
- 目前仍为开发分支；未形成 S1–S6 的发布就绪结论。
