## 基线与契约

- 从 `origin/main` 的 `ee57f6795c644e9c6d62d9d20ce5442831a613b6` 创建分支，之后已合入 `origin/main` 的 `f2aa81d`；同步后后端全量测试和前端门禁均通过。
- 保留旧流程 schema `1.0`、`2.0`、`3.0` 和旧引用型 ForEach 的默认行为。内联控制区域使用 schema `4.0`、`flow.control.*@1.0.0`，要求显式主请求预算。
- 区域拥有稳定 ID、owner、role、入口、出口、独立 DAG；定义节点不按运行轮次复制。运行轮次通过实例 ID 和 checkpoint 表示。
- schema `4.0` 的定义可以表达固定版本引用体，但发布时明确拒绝；当前只执行内联区域。

控制块模板共 12 类：集合遍历、重复次数、IF、Switch、While、DoWhile、Until、Parallel、Try、步骤组、主动失败、返回调用方。Break、Continue、Return 已有运行契约；Break/Continue 可在直接所属的串行循环体内通过面板添加，Return 可从节点库添加，节点库及配置面板均明确提示直接运行会以 `RETURN_OUTSIDE_CALL` 失败。控制节点在画布上显示实际控制类型。面板提供配置与区域 JSON 编辑；配置 JSON 需显式应用，未应用草稿锁定同一配置的可视化编辑，过期草稿不会覆盖较新配置。条件循环可逐字段编辑状态初始化、来源路径及每轮更新。IF、条件循环与 Switch 规则分支可通过表单编辑嵌套的 ALL/ANY/NOT 条件和比较操作；Switch 模式切换只在能保持原分支语义时开放，分支改名与排序保留分支 ID 和区域归属。区域面板可视化修改等待步骤的时长、向串行区域追加等待和固定版本的接口步骤；未应用的区域 JSON 草稿会锁定这些可视化操作，外部更新不会静默覆盖草稿。区域画布现可显示内部连线与入口、出口，拖动节点并保存位置；选中串行区域步骤后可在安全连线中插入等待或固定版本的接口步骤，有条件或字段映射的连线会拒绝直接插入。区域画布还可确认后删除无条件、无字段映射、无剩余引用的线性步骤并重接连线。无条件、无字段映射、无内部节点依赖的线性区域可前后移动步骤，保留节点与连线 ID 并更新入口、出口。区域内可在安全连线后插入控制块，选择该块可配置条件与策略、进入子区域；嵌套 Switch 的分支变更与区域定义一并提交。删除嵌套控制块会同时移除其子区域；有条件、映射或引用时拒绝删除。前端在第 4 层后阻止继续嵌套，与后端深度上限一致。区域内合法连线的自由编辑、一般图结构的步骤删除与重排、区域边界折叠仍未完成；后端要求普通步骤最多一条出边，分叉须由控制块表达。选中无字段映射的主画布连线后添加控制块，可在一次编辑中完成插入与自动布局；有映射的连线会拒绝直接插入。主画布中有单一入口、出口的普通节点可包装为步骤组或集合遍历，保留原节点 ID；无输入、输出、映射、嵌套和外部引用的单步骤控制块可确认后拆解；无跨区域引用、普通线性连线的多步骤组也可确认后拆解，保留内部节点和连线 ID。

本轮区域画布增加线性步骤的指定序位移动：一次调整可跨越多个步骤，保持节点 ID、连线 ID及区域入口/出口一致；区域存在条件连线、字段映射或节点引用时仍拒绝重排。Try 面板增加 Catch 的可视化增删、排序、名称和错误码编辑，以及 Finally 区域的启用/确认移除；结构变动在一次定义更新中同步配置和所属区域，删除嵌套区域时一并移除子区域。新增 Catch 使用占位错误码，保存业务流程前仍须改为实际错误码。这些是编辑能力增量，尚无本轮保存、发布、执行的浏览器验收。

本批允许从区域画布拖动普通连线端点，按目标前驱重排无条件、无映射、无节点引用的线性路径；重排保留节点和边 ID，并重算入口与出口，不创建隐式分支。Try 面板可编辑预期错误码，与 Catch 的匹配错误码分开；两种列表在服务端均拒绝空白、首尾空格、重复或超过 100 字符的错误码。

主画布编辑菜单现可从选中的普通节点开始选择结束步骤，把一条连续线性路径包装为步骤组或集合遍历。原子图操作保留内部节点与连线 ID，外部入口/出口重接到控制块；有多入口/多出口、映射、条件连线、跨边界引用或不支持的节点类型时拒绝。该能力尚未扩展到分支子图或区域内部。主画布线性多步骤组现可安全拆回普通节点。选中安全的主画布连线后添加接口或等待节点，也可直接插入并自动重接；有字段映射的连线仍会拒绝插入。
